# Feature Design Plans

RDSS uses Feature Design Plans (FDPs) are planning documents used within RDSS for software architectural designs and discussion around upcoming epics with the goal of having a dedicated space for developers to have technical discussions internally in advance of feature refinement discussions.

The directory for this documentation [can be found here](https://drive.google.com/drive/folders/1a4Qa93_P9-2ollFeWAOeoTNSfuGZh2VH).

Each document requires 1 - 2 directly responsible individuals (DRIs).  The DRI is accountable for ensuring that the FDP exists, is prepopulated with as much information as they have available prior to review with RDSS, and ensure that the FDP gets added to the agenda and reviewed within RDSS.
